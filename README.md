# Character Building Rules
## Feat Changes
**[Garden of Healing](https://2e.aonprd.com/Spells.aspx?ID=2166)**
- In Exploration Mode the total healing received is `1d8 per spell rank`
  - _This puts it in line with other spells_
- Add the following to the description. _You can sustain the spell if cast in combat 1 more time post combat_

**[Rippling Spin](https://2e.aonprd.com/Feats.aspx?ID=7499&NoRedirect=1)**
- **Traits:** Flourish, Monk, Occult, Water ⇒ **~~Flourish,~~ Monk, Occult, Water**

**[Timber Sentinel](https://2e.aonprd.com/Feats.aspx?ID=4284)**
- **Traits:** Impulse, Kineticist, Plant, Primal, Wood ⇒ **Impulse, Kineticist, __Overflow__, Plant, Primal, Wood**

**Various Impulses + Channel Aura**
- For certain Impulses and the channel aura associate with them gain the **Subtle** trait (designed to make whisper on the wind not completely awful)

**Dirty Trick**
- **Traits:** Attack, General, Manipulate, Skill ⇒ **~~Attack,~~ General, Manipulate, Skill**
